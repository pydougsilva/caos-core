# C.A.O.S — Bootstrap de Sessão (Claude Code)

Este repositório usa o protocolo C.A.O.S (Cognitive Autonomous Operational System).

## Instrução obrigatória antes de qualquer operação

1. Leia `AGENTS.md` — autoridade máxima deste repositório
2. Leia `rag/index.md` — mapa de módulos operacionais
3. Siga o protocolo declarado em `AGENTS.md`

## Este arquivo é um adapter

`CLAUDE.md` é o mecanismo de carregamento para Claude Code.
Não contém o protocolo — apenas instrui o carregamento dele.
O protocolo completo está em `AGENTS.md`.

Documentação do adapter: `.caos/adapters/claude.md`
