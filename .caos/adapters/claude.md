# Adapter — Claude Code
versao: 1.0

## Ferramenta

Claude Code (CLI + VSCode Extension — Anthropic)

## Mecanismo de carregamento

`CLAUDE.md` na raiz do projeto.
Claude Code lê `CLAUDE.md` automaticamente como instruções de projeto.

## O que este adapter faz

Instrui Claude Code a carregar `AGENTS.md` antes de operar.
Não duplica o protocolo. Não substitui `AGENTS.md`.

## O que este adapter não é

- Não é o protocolo C.A.O.S
- Não é autoridade sobre operações
- Não substitui `AGENTS.md`

## Protocolo completo

`AGENTS.md` — raiz do projeto.
